# Антипаттерны виджетов

| Плохой ход | Последствие | Решение |
| --- | --- | --- |
| `case block.title` для категории, картинки или эмоджи | Переименование меняет поведение | Хранить ссылку и файл в полях блока; неоднозначный способ оформления согласовать |
| `catalog.subcollections` искать по тексту заголовка | Маскирует ошибку связи | Проверить значение поля блока через `view=full` и исправить запись |
| Список слайдов или FAQ зашит в `snippet.liquid` | Редактор не может менять список | `BlockListWidgetType` с подходящим шаблоном |
| Один `index` и `$widget.find()` для слайдера | Состояние разных экземпляров смешивается | Локальное состояние внутри `WidgetLifecycle.mount` или `$widget.each()` |
| Слайдер не выполняет требуемые действия: стрелки, свайп или обновление в редакторе | Не работает часть сценариев | Исправить в текущей реализации; сменить библиотеку существующего виджета только по явному запросу |
| Секция без стандартных layout-настроек | Дизайн нельзя подстроить в редакторе | Фон, ширина и отступы через `my-layout` |
| `limit: 1` у `widget_lists.*.widgets` | Следующие секции скрыты даже после добавления в редакторе | Выводить весь список, лишние размещения снимать со списка |
| Вся секция `snippet.liquid` на одной строке | Изменения трудно проверять и сопровождать | Форматировать HTML и Liquid до передачи кода в MCP, сохраняя значимые пробелы |
| `.png` с JPEG внутри для предмета на цветном фоне | Белая подложка разрушает композицию | Проверить формат и альфа-канал файла, затем видимые края на витрине |

`case` по техническому режиму и общий `$widget.find()` для одинакового действия без состояния допустимы. Предупреждения о паттернах требуют оценки назначения кода и не блокируют запись.
