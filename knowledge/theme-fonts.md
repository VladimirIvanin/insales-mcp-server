# Свои шрифты для всей темы: system_v4_fonts

Глобальное подключение пользовательских шрифтов темы поколения 4 выполняет сниппет `system_v4_fonts`. В настройках темы указывается имя CSS-файла из assets темы, в котором объявлены шрифты, а не имя файла WOFF2 и не URL. Основной текст и заголовки настраиваются независимо. Этот сценарий нужен для запросов «установить свой шрифт», «подключить локальные шрифты», «заменить шрифты темы» и переноса типографики макета.

| Назначение | Включить пользовательский шрифт | Имя CSS-файла темы | Внешний CSS, если asset не задан |
| --- | --- | --- | --- |
| Основной текст | `custom-font-family-enabled` | `custom-font-family-asset` | `custom-font-family-url` |
| Заголовки | `custom-font-family-heading-enabled` | `custom-font-family-heading-asset` | `custom-font-family-heading-url` |

Порядок работы агента:

1. Выбери нужную тему через `list_themes` и `get_theme`. Прочитай `get_theme_settings`, список файлов через `list_theme_assets` и текущий `system_v4_fonts` через `get_theme_asset`. Убедись, что сниппет поддерживает оба поля `*-asset` и используется темой. Наличие механизма в руководстве не подтверждает его наличие в конкретной теме; не заменяй весь системный сниппет по примеру.
2. Подготовь файлы шрифта для нужных начертаний, весов и алфавитов. Загрузи их в выбранную тему через `create_theme_asset`: бинарные данные передаются через `attachment` в Base64; имя файла передай в `name`, тип — в `type`. Формат параметров проверь в схеме инструмента. Для каждого создания сохрани отдельный `operation_id` до вызова; при потере ответа проверь список файлов и содержимое перед новым действием: повторная отправка не защищена сервером.
3. Создай CSS-файл, например `custom-fonts.css`, с объявлениями `@font-face`. Используй подтверждённые URL загруженных файлов. Обычный `.css` не обрабатывает Liquid: не оставляй в нём `{{ 'font.woff2' | asset_url }}`. Существующий CSS сначала прочитай и при необходимости измени через `update_theme_asset` с его `updated_at` в `parameters.expected_updated_at`.
4. Через `update_theme_settings` передай в `parameters.settings` флаг включения и имя CSS для нужной роли. Передай `updated_at` прочитанных настроек как `parameters.expected_updated_at`. Один CSS-файл может содержать оба семейства; тогда его имя укажи в обоих полях. Настройки выбора самого семейства проверь по схеме и существующим стилям темы: подключение CSS с `@font-face` лишь объявляет шрифт, а применение требует совпадающего `font-family`. Не придумывай название настройки семейства и не заменяй её глобальным `* { font-family: ... }`.
5. Проверь сохранённые настройки и витрину: подключён нужный CSS, файлы шрифтов загружаются без ошибок, вычисленный `font-family` соответствует выбранному семейству. Проверь основной текст и заголовки, используемые веса и кириллицу, если она нужна. Для опубликованной темы изменения сразу влияют на витрину.

Пример CSS с условным URL — замени его URL загруженного файла; для других весов добавь соответствующие объявления:

```css
@font-face {
  font-family: 'Brand Sans';
  src: url('https://cdn.example.com/brand-sans-regular.woff2') format('woff2');
  font-weight: 400;
  font-style: normal;
  font-display: swap;
}
```

Пример объекта `parameters.settings` для подключения одного CSS к обеим ролям (выбор семейства задаётся отдельно по схеме темы):

```json
{
  "custom-font-family-enabled": true,
  "custom-font-family-asset": "custom-fonts.css",
  "custom-font-family-heading-enabled": true,
  "custom-font-family-heading-asset": "custom-fonts.css"
}
```

Условия подключения в `system_v4_fonts`:

- При включённом `*-enabled` и непустом `*-asset` сниппет получает URL через `asset_url_if_exists` и выводит `preload` и `stylesheet`. Эта ветка имеет приоритет над `*-url`, системным шрифтом, Google Fonts addon и переданными в сниппет ссылками соответствующей роли.
- Если имя asset непустое, но файл отсутствует, ссылки не выводятся и перехода к внешнему URL или системному шрифту нет. Исправь имя или загрузи файл; для возврата к URL очисти `*-asset` и проверь `*-enabled` и `*-url`.
- При пустом `*-asset` либо выключенном `*-enabled` действует прежняя ветка: пользовательский URL при включённом флаге, иначе `fonts[settings.font-family]` или `fonts[settings.font-family-heading]`; в этой же ветке могут добавляться Google Fonts addon и `custom_font_family_link` / `custom_font_family_heading_link`.

Не дублируй подключение в `snippets/styles.liquid`, layout или отдельных виджетах. Глобальная установка шрифтов должна использовать штатные настройки темы и `system_v4_fonts`.

Источник поведения: предоставленный пользователем код `system_v4_fonts` с `static_version = '6.99'`. Это значение относится к статическим ресурсам сниппета и само по себе не подтверждает поддержку полей в другой теме.
